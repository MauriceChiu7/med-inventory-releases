# 藥物儲倉管理：發布版本

這裡只放最新版的 Mac App（v2.1.7），程式會自動從這裡檢查與下載更新。

手動安裝：下載 [藥物儲倉管理_v2.1.7.zip](藥物儲倉管理_v2.1.7.zip)，解壓縮後把「藥物儲倉管理.app」拖到桌面或「應用程式」資料夾。壓縮檔裡也有離線版的使用教學（v2.1.7_教學.html）。

這一版的變更：沒有功能變更，用來測試客戶電腦上的自動更新（v2.1.6 起內附根憑證）。
